# Heritage-AR V2 🏛️

**AI-Powered Augmented Reality for Digital Heritage Preservation**

## Overview
Heritage-AR V2 is a smartphone-focused project designed to bring historical monuments to life using augmented reality, 3D reconstruction, and AI-assisted storytelling. It aims to make cultural heritage more accessible and historical education more interactive.

## Key Features
- 3D historical monument reconstruction
- Interactive AR experiences using Unity and AR Foundation
- AI-assisted historical storytelling
- Immersive educational visualizations
- Planned offline-friendly content and location-based AR

## Technology Stack
- Unity
- Blender
- AR Foundation
- ARCore and ARKit
- AI-assisted storytelling technologies

## Getting Started
1. Install a compatible Unity Editor version.
2. Install Blender for 3D asset creation.
3. Clone this repository.
4. Open the Unity project using Unity Hub.
5. Install the required packages through Unity Package Manager.
6. Open the main scene and follow the project documentation.

## Project Structure
- `UnityProject/` — Unity application
- `BlenderAssets/` — 3D models and source assets
- `SampleData/` — Sample historical content
- `Tests/` — Test cases
- `docs/` — Architecture and technical documentation
